Rustok is a non-custodial multi-chain Ethereum wallet with a built-in transaction security scanner — decode, simulate, and flag risk before you sign.

Download for Android How it works

Built, not promised

Every capability below is live in the app today — running on Sepolia testnet.

🔑 Non-custodial by design

Your seed phrase is generated and held on-device. Rustok never has access to your keys or your funds — architecturally, not by promise.

🛡️ TxGuard security scanner

Every transaction is decoded, simulated, and checked against a security rule set before you sign — with a clear risk badge and per-finding breakdown.

💸 Send / Receive / History

A real transaction feed with pending-state tracking and explorer links — the fundamentals, done properly.

🔒 PIN + biometric lock

Argon2id-hashed PIN, Face ID / fingerprint unlock, background auto-lock.
