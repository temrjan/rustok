# Архив документации

Файлы здесь описывают направления, которые проект больше не ведёт. Они сохранены,
потому что фиксируют **факт или замысел**, а не инструкцию: по ним видно, что было
сделано и почему от этого отказались. Как руководство к действию их читать нельзя.

## Агентский слой (снят 2026-08-30)

Крейты `agent-wallet`, `agent-mcp`, `agent-dapps` и вся их дистрибуция удалены.
Действующая реализация MCP живёт в отдельном репозитории `rustok-org/mcp`
(запись в реестре — `io.github.rustok-org/rustok-wallet`).

| Файл | Что фиксирует |
|---|---|
| `PLAN-LLM-WALLET.md` | Исходный замысел разворота в «кошелёк для LLM» — объясняет, зачем всё это затевалось |
| `PHASE4-E2E-REPORT.md` | Реальный E2E-прогон на Sepolia, включая проведённую транзакцию |
| `PLAN-SAAS-MVP-TELEGRAM.md` | План SaaS вокруг Telegram-бота выдачи ключей |
| `RUSTOK_LLM_AGENT_PLAN_RIG.md` | Статус Rig: **отложен, не отменён** — может вернуться chat-first |
| `HANDOFF-ENGINEER.md` | Роль Инженера в редакции агентского пивота |
| `HANDOFF-REVIEWER.md` | Роль Ревьюера в редакции агентского пивота |

Роли Инженера и Ревьюера сейчас описаны в скиллах `/engineer` и `/reviewer`, а состав
команды — в `docs/TEAM-CONSTITUTION.md`. Два хэндоффа выше сохранены как исторический
снимок: они открываются фразой о переходе от «mobile wallet for humans» к «Agent Wallet
Infrastructure», и этот переход отменён.
