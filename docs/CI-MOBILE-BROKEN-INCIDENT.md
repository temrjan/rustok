## 2. Root cause

The Mobile job in `.github/workflows/ci.yml` (lines 82-104) runs:

```
- npm ci  (workspace root)
- npm run typecheck  (cwd=mobile, runs `tsc --noEmit`)
- npm run lint
- npm test
```

`mobile/src/lib/walletHandle.ts` and 3 other TS files import from
`react-native-rustok-bridge`. This package is **not** an npm dep — it is a
`uniffi-bindgen-react-native`-generated TypeScript module produced from
`crates/rustok-mobile-bindings`. It is **not committed to git** (generated
artifact convention) and is **not regenerated by `npm ci`** (npm has no
knowledge of the cargo + uniffi build pipeline).

On a developer machine the bindings persist on disk after a single
`cargo build` + uniffi codegen (Phase 1 onboarding step in `mobile/README.md`).
On a fresh CI runner with no Rust toolchain step, the binding directory is
missing → `tsc --noEmit` fails with TS2307 on first import.

## 6. Interim gate — local CI mirror decision tree

Until D4 lands (§ 7), every Phase 4 feat-branch commit MUST include in commit
message a local-mirror evidence block. Run command (from `mobile/`):

```bash
npm run typecheck && npm run lint && npm test
```

Evidence block format:

```
Local CI mirror (interim gate per CI-MOBILE-BROKEN-INCIDENT § 6):
- npm run typecheck → PASS / FAIL
- npm run lint → PASS / FAIL (warnings count noted)
- npm test → N suites / N tests passed
```

### Decision tree (Reviewer 2026-05-07, refined per Engineer C1)

**(a) Green** → commit OK; copy mirror output snippet into commit message
body. Lint warnings tolerated as long as `errors=0` (existing Phase 3
baseline).

**(b) Intermediate red in push batch** → gate is evaluated on **HEAD**
immediately before `git push`, NOT on every intermediate commit. WIP commits
with red mirror are acceptable provided they are squashed / amended /
cleaned up before push (alignment with how PR CI gates the latest tip
commit). Do not push N-commit batch where HEAD has red mirror.

**(c) Persistent red** →
- **threshold:** 2-3 focused-fix attempts ИЛИ root cause unclear after ~30
  min of investigation
- **action:** STOP. Escalate via new INCIDENT entry (or extend existing § 5
  followup row) + Капитан signal request.
- **NOT permitted:** self-fix > 1 commit without escalation (Constitution
  §6.5 — capitulation under impatience). Do not paper over with skipped
  tests or `// @ts-expect-error` pseudo-fixes.

**(d) Mirror scope** →
- **Default (M0 / M1 / M2 / M3 / M4 per current Phase 4 plan):** `mobile/`
  only — `npm run typecheck && npm run lint && npm test`. Phase 4 is pure
  TS per F1 decision (Keychain wrapper) + M2 Argon2 (`react-native-argon2`
  is JS package wrapping native, not a cargo crate) + M4 ImportPhrase
  (consumes existing `walletHandle.importWalletFromMnemonic`, no new bridge
  method).
- **Conditional (currently INACTIVE):** expand to
  `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`
  IF a milestone touches **new Rust crate code** OR **adds a new bridge
  method**. **Activation triggers a re-review of this § 6.** Engineer must
  not silently expand scope without explicit Reviewer confirmation.
